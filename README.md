# Stellar Burger

Учебный проект курса «React-разработчик» (Яндекс Практикум).

## Ссылка на приложение

**Задеплоенная версия:** [https://nemkocat.github.io/react-burger/](https://nemkocat.github.io/react-burger/)

## Функционал

- Сборка бургера с drag-and-drop
- Модальные окна ингредиента и заказа
- Redux Toolkit: ингредиенты, конструктор, заказ, пользователь, ленты заказов
- Роутинг и защищённые маршруты
- Регистрация, авторизация, профиль, восстановление пароля
- Лента заказов и история заказов через WebSocket
- Unit-тесты слайсов (Vitest) и e2e-тесты конструктора (Playwright + HAR)

## Стек

- React 19, TypeScript, Vite
- Redux Toolkit, React Router
- React DnD
- Vitest, Playwright

## Запуск

```bash
npm install
npm run dev
```

## Тесты

```bash
# Unit-тесты редьюсеров
npm test

# E2E Playwright (HAR-моки API)
npm run e2e
```

## Сборка и деплой

```bash
npm run build
npm run deploy
```

## Проверки перед коммитом

```bash
npm run lint
npm run build
npm test
```

## Ветки

- `main` — основная ветка
- `sprint5` — лента заказов и WebSocket
- `sprint6` — тестирование и деплой

## Процедура создания коммита с проверками

При создании коммита автоматически запускаются проверка линтерами `stylelint`, `eslint` и форматирование `prettier`.

Если линтер обнаружит ошибки:

- Коммит создан не будет
- Необходимо исправить все выявленные проблемы
- Добавить исправленные файлы в индекс: `git add .`
- Повторить коммит

**Рекомендация:**  
Для предотвращения ошибок на этапе коммита предварительно выполните:  
`npm run lint`. Это позволит выявить и исправить проблемы до создания коммита.

Есть также команды для запуска проверок по отдельности:

- `npm run eslint` — проверка и автоисправление ESLint
- `npm run stylelint` — проверка и автоисправление Stylelint
- `npm run prettier` — форматирование кода

Для создания коммита рекомендуется запускать команду `npm run commit`.
